# 5.8.6

잘못된 NVS 패드 JSON이 패드 준비를 건너뛰어 Wi-Fi MAC이 0으로 설정되던 경로를 차단했습니다. Wi-Fi MAC은 패드 설정과 독립적으로 eFuse에서 읽습니다. 잘못된 패드 문자열은 장치 내부 pad_cfg_bad에 보관하며 빈 유효 목록으로 복구합니다. 정상 패드 설정은 변경하지 않습니다.

SD 상태 알림을 우측 하단 280px 알림으로 줄이고 확인 버튼을 제거했습니다. 3초 자동 닫힘과 첫 로딩 SD 상태 알림을 유지합니다. SD 미사용 시 내장 화면에 적용됩니다.

Wi-Fi 비밀번호/PIN/토큰, OTA 프로토콜과 릴레이 재시작 ABI는 유지합니다. 개인 주소·설정은 공개 릴리스에 포함하지 않습니다. 장치별 등록 정보는 NVS에 저장합니다. SD 미사용 환경에서 확인하며 실제 패드 깨우기와 순간 GPIO 파형은 이번 릴리스 검증 대상이 아닙니다.

5.8.6 관리자 페이지/API/OTA는 사용자 요청에 따라 로그인 없이 동작합니다. 같은 LAN에서 전원 제어와 업데이트가 가능하므로 신뢰할 수 있는 내부망에서 사용하며 외부 포트 개방은 전제로 하지 않습니다. Wi-Fi 접속 비밀번호와 Linux companion 토큰은 유지합니다. OTA 체크섬·요청 헤더·릴레이 보호 검사는 유지합니다. 기존 PIN 값은 마이그레이션 호환을 위해 저장돼 있어도 사용하지 않습니다.
