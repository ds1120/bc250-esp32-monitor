# 하드웨어 기준과 확인 범위

## 확인된 하드웨어

| 항목 | 현재 프로젝트의 기준 |
|---|---|
| PC | AMD BC-250, systemd 기반 Linux (현재 실사용 CachyOS) |
| ESP32 보드 | ESP32-2432S028 |
| LCD 드라이버 | **ST7789** |
| PlatformIO 빌드 환경 | **st7789** (`pio run -d firmware -e st7789`) |
| USB 데이터 연결 | USB-C → CH340 USB-UART → ESP32 UART0 |
| USB 통신 | Linux H4 Bluetooth, 송신·수신 모두 921600 baud, 8N1, 흐름 제어 없음 |
| 릴레이 제어 | GPIO22, HIGH = 전원 공급 요청 ON |

LCD의 ST7789는 현재 장치에서 동작을 확인한 빌드 설정입니다. 런타임에서 패널 ID를 읽어 자동 판별한 결과가 아닙니다. LCD 자동 감지는 수행하지 않습니다. SD카드에 LCD 칩 종류를 추측해 저장하지 않습니다.
다른 LCD나 배선의 보드는 이 문서의 '동일 하드웨어'에 해당하지 않습니다. 화면 드라이버·핀 설정을 검토하고 별도 빌드해야 합니다. ILI9341 빌드 환경이 존재해도 현재 장치는 ST7789입니다.


## 배선 정보 상태

현재 사용 구성은 ESP32 + 릴레이 + BC-250입니다. GPIO22/HIGH는 펌웨어의 제어 정의입니다. 실제 릴레이 접점(COM/NO/NC), 릴레이 전원·GND, ATX PS_ON/대기전원 연결, USB 전원 절연 회로는 이 문서에서 검증하지 않았습니다.

사용자가 다른 PC의 로컬 문서에서 실제 배선 정보를 추후 갱신할 예정입니다. 확인 전까지 추측한 배선도나 ATX 핀 연결 지침은 제공하지 않습니다. 설치자는 자신의 릴레이 극성과 전원 회로를 별도로 검증해야 합니다.

## 자동 수집과의 구분

LCD ST7789, 릴레이 핀과 전원 배선은 런타임 자동 감지 대상이 아닙니다. PC 이름·IP·USB 장치 경로·Bluetooth 주소는 운영체제/연결된 장치에서 읽습니다. SD에는 네트워크·장치의 누락된 정보만 채우며, LCD 종류를 추측해 저장하지 않습니다.
