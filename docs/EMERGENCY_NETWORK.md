# USB 비상 인터넷 중단 기록

5.8 후보에서는 Bluetooth USB HCI를 공유하는 비상 인터넷 기능을 구현했으나, USB 연결 상태의 BC-250 부팅 실패가 보고되어 5.8.1에서 관련 펌웨어 코드·API·관리자 버튼·PC 도구를 제거했습니다. 실험 소스와 5.8 후보 bin은 현재 배포에 포함하지 않습니다.

5.8.1 업데이트 중 PC 실행 유지와 릴레이 HIGH 복귀는 확인했습니다. USB를 연결한 상태의 콜드 부팅과 업데이트 후 Bluetooth 재연결은 아직 확인하지 못했습니다. 제거만으로 부팅 문제가 해결됐다고 판단하지 않습니다.

이미 5.8 PC 도구를 설치한 환경에서는 다음 명령으로 비상 인터넷 서비스를 중지하고 자동 실행을 해제합니다. 이 장치에서는 inactive/disabled를 확인했습니다.

```bash
sudo systemctl disable --now bc250-esp-network.service
```

기존 ESP32의 Wi-Fi 관리자 화면과 Wi-Fi 모니터링은 유지됩니다.
