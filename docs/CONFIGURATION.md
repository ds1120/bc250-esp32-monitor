# 설정 수명 주기 — 5.8.5 Wi-Fi 운용

## 저장 위치

- NVS: Wi-Fi/PIN/토큰·터치 보정과 핵심 PC/패드 운영 설정
- SD `/bc250/settings.json`: 사용자 설정·패드 구성과 화면/외형 설정. 유효한 SD 값은 시작 시 적용하고 핵심 항목은 NVS에도 보존
- SD HTML/CSS/JS/이미지: 사용자 화면. SD가 없으면 펌웨어 내장 화면 사용

핵심 캐시 항목은 PC 주소·포트, 패드 구성 전체(필요한 IRK 포함)·수동/자동 모드·활성화, 모니터링 간격, 화면 복귀 시간, 수집된 PC 이름/대상 정보입니다. 값이 달라질 때만 NVS에 씁니다. 개인 주소는 현재 장치에만 저장하며 공개 소스에는 포함하지 않습니다.

## PC와 패드 설정

최초 `configure.py --host <실제_PC_IP>` 또는 SD JSON의 `network.agent_host`/`agent_port`를 지정합니다. USB 자동 수집은 현재 사용하지 않습니다. 기본 포트 9091은 개인 정보가 아닌 양쪽 프로토콜 상수입니다.

패드는 Linux에 등록된 지원 컨트롤러를 Wi-Fi로 수집하거나 SD `gamepads`에 호스트 대상·컨트롤러 목록을 지정합니다. 관리자 화면의 수동 주소 저장은 전체 현재 패드 구성을 NVS에 보관하고 자동 동기화를 중지합니다. `internal_saved`는 현재 패드 구성과 NVS가 일치하는지 표시합니다. 주소를 다른 패드로 바꾸면 기존 IRK를 이전하지 않습니다.

현재 사용자의 패드 1개는 개인 설정으로 NVS에 저장하고 업데이트 후 일치를 확인했습니다. 이 주소는 공개 기본값이 아닙니다. 실제 SD 제거 부팅/패드 깨우기 전체 시험은 별도로 수행해야 합니다.

## SD 없는 동작

핵심 Wi-Fi 모니터링·전원 제어·OTA·등록 패드 설정은 NVS와 내장 화면을 사용하도록 설계됐습니다. 사용자 SD 이미지/웹 파일은 읽을 수 없으며 일부 LCD 외형은 기본값을 사용합니다. 새 빈 보드의 전체 초기 설치와 카드 제거 실물 시험은 미완료입니다. 카드는 전원을 끈 상태에서 탈착합니다.

## USB와 전원 진단

5.8.5는 USB 제어·상태 API와 실행 데이터 경로를 제거합니다. USB Serial 칩의 물리적 장치 등록은 펌웨어가 끄는 기능이 아닙니다. USB 연결 상태 부팅 문제는 5.5에서도 보고됐으며 원인 미확정입니다. 평소에는 케이블을 제외합니다.

원격 종료를 임시 차단하던 파일은 사용자 요청으로 비활성화됐습니다. 관리자 화면과 LCD 모두 정상 종료/재부팅을 사용합니다. 필요하면 `/etc/bc250-power-manager/block-power-actions` 파일로 진단 차단을 다시 설정할 수 있으나 기본 설치에서 자동 생성하지 않습니다. 요청 IP·동작·결과만 journal에 기록하고 인증값은 기록하지 않습니다.
