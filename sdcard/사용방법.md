# SD카드 화면과 설정

FAT32 SD카드를 ESP32 슬롯에 넣습니다. 펌웨어는 `/bc250/`에 없는 기본 화면과 설정을 생성합니다. 기존 파일은 자동 덮어쓰지 않습니다.

- `index.html`, `style.css`, `app.js`: 관리자 화면
- `settings.json`: 현재 동작 설정과 USB에서 수집한 비어 있던 PC 정보
- `settings.example.json`: 비밀정보가 없는 설정 예제

실제 PC·Bluetooth 정보가 들어간 `settings.json`은 공개 저장소에 올리지 마세요. Wi-Fi 비밀번호·PIN·토큰은 이 파일에 저장하지 않습니다.

관리자 페이지의 SD 항목에서 파일 업로드·현재 설정 다운로드·기본 화면 복원을 사용할 수 있습니다. 복원은 기존 화면 파일을 `.bak`으로 보관하며 동작 설정을 덮어쓰지 않습니다. 문제가 있으면 현재 패널 주소의 `/recovery`에서 내장 화면을 엽니다.

세부 우선순위는 [설정 문서](../docs/CONFIGURATION.md), LCD와 배선 기준은 [하드웨어 문서](../docs/HARDWARE.md)를 확인하세요. 파일을 SD에 복사하는 것만으로 펌웨어가 설치되지는 않습니다.
